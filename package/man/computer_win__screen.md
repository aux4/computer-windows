#### Description

Lists the displays: `index` (for `screenshot --display`), `main`, `scale` (DPI / 96), the bounds `x`, `y`, `width`, `height` in logical pixels and the physical `pixels` size.

#### Usage

```bash
aux4 computer win screen
```

#### Example

```bash
aux4 computer win screen
```

```json
{"displays":[{"height":768,"id":65537,"index":0,"main":true,"name":"\\\\.\\DISPLAY1","pixels":{"height":768,"width":1024},"scale":1,"width":1024,"x":0,"y":0}]}
```
