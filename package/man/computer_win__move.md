#### Description

Moves the mouse cursor to screen coordinates (logical pixels). It is always real input.

#### Usage

```bash
aux4 computer win move --x <x> --y <y>
```

--x          X coordinate in screen logical pixels
--y          Y coordinate in screen logical pixels

#### Example

```bash
aux4 computer win move --x 500 --y 300
```

```json
{"mode":"foreground","x":500,"y":300}
```
