#### Description

Turns off the stop switch (removes the `STOP` file). If `AUX4_COMPUTER_STOP=1` is set it says input is still stopped and why.

#### Usage

```bash
aux4 computer win resume
```

#### Example

```bash
aux4 computer win resume
```

```json
{"file":"C:\\Users\\sally\\AppData\\Local\\aux4-computer\\STOP","stopped":false}
```
